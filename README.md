## เว็บนี้คืออะไร

**Pokedex XP** เป็นเว็บคู่มือสำหรับคนที่เพิ่งเริ่มเล่น **Pokémon Legends: Z-A** (ชื่อโปรแกรมคือ Pokedex XP ส่วน Pokémon Legends: Z-A คือชื่อเวอร์ชันของเกม) ที่ตอบคำถามเดียวกันให้ทุกตัวในเกมว่า

> "ตัวนี้ควรจับนิสัยอะไร เพศอะไร ใช้ท่าอะไร วางไว้ปุ่มไหน แพ้อะไร แก้ทางยังไง แล้วจะเทรนยังไง"

เปิดมาเป็นหน้า Pokédex (หลัก 232 ตัว + Mega Dimension DLC 132 ตัว)ในหน้าต่างสไตล์ Windows XP กดโปเกมอนตัวไหนก็ได้ จะเด้งหน้าต่างรายละเอียดขึ้นมา พร้อมคำแนะนำที่ปรับตาม**สายการเล่น**ที่คุณเลือก

## ฟีเจอร์

### 🔎 Pokédex (หน้าแรก)
- แบ่งเป็น 2 section: **Pokédex หลัก (232 ตัว)** และ **Mega Dimension DLC (132 ตัว)** ต่อจากกัน มีปุ่มกระโดดไปแต่ละ section การค้นหา/กรอง/เรียงลำดับใช้กับทั้งสอง section
- เลขลำดับ DLC เริ่มที่ `#001` ใหม่ (มีป้าย DLC กำกับ) ปุ่มก่อนหน้า/ถัดไปในหน้ารายละเอียดเดินตาม section ของตัวนั้น
- แสดงเป็นการ์ดพร้อมสไปรต์พิกเซลและไอคอนธาตุ
- ค้นหาได้ทั้งชื่อ **ญี่ปุ่น / อังกฤษ / โรมาจิ / เลขลำดับ** (เช่น `ピカチュウ`, `pika`, `25`)
- กรองตามธาตุ, กรองตาม**สายการเล่นที่เหมาะ**, เรียงตามลำดับ Pokédex / ชื่อ / ค่าพลังรวม / ความเร็ว / ความเหมาะสมของสาย
- ชื่อแสดงเป็น **ญี่ปุ่น (อังกฤษ)** พร้อมโรมาจิ

### 🎯 4 สายการเล่นต่อโปเกมอนหนึ่งตัว
โปเกมอนทุกตัวถูกจัดอันดับว่าเหมาะกับสายไหนมากที่สุด และรองลงมา

| สาย | แนวคิด |
|---|---|
| **สายบุกเร็ว** | ตีแรงและเร็ว จบการต่อสู้ก่อนที่ศัตรูจะขยับ |
| **สายอึดตีกลาง** | รับได้ ตีกลับได้ สมดุลระหว่างโจมตีกับความอึด |
| **สายถึก ตั้งรับ** | ทนทาน ฟื้นฟู ถ่วงเวลา เหมาะกับมือใหม่ที่อยากเอาตัวรอด |
| **สายซัพพอร์ต สถานะ** | ใช้ท่าสถานะ ลดพลังศัตรู วางกำแพง ช่วยทีม |

หน้ารายละเอียดจะเปิดที่สายที่เหมาะที่สุดก่อน กดเลือกสายอื่นแล้วทุกอย่างด้านล่างเปลี่ยนตามสายนั้น:

- **นิสัยที่ดีที่สุด** พร้อมเหตุผล และวิธีใช้ Mint ปรับผลของนิสัย
- **ท่าที่ดีที่สุด 4 ท่า** (นับทุกประเภท) และ**ชุดสำรอง 4 ท่า** พร้อมจัดวางบนปุ่ม **A / B / X / Y** แบบเครื่อง Switch
- **แผน IV/EV** และค่าที่ควรดันเป็น 31 ก่อน
- **ธาตุที่ชุดท่านี้ตีแรงใส่**

ส่วนที่ไม่เปลี่ยนตามสาย: เพศที่ดีที่สุด, ธาตุแพ้/ชนะ และท่าที่ใช้สวนทาง

### 🧬 วิวัฒนาการ
- แท็บ **วิวัฒนาการ** ในหน้ารายละเอียด: แผนผังสายวิวัฒนาการ (เรียงแนวนอน สายที่แตกหลายร่างอย่าง Eevee ก็เรียงแบบเดียวกัน) รวม **Mega Evolution** ของตัวที่มี — กดที่ร่าง Mega เพื่อเปลี่ยนรูปใหญ่และดูค่าพลัง ธาตุ ความสามารถ และตารางแพ้/ชนะของร่าง Mega พร้อมเงื่อนไข (เลเวล, ไอเทม, ความสนิท, ช่วงเวลา, รู้ท่า, แลกเปลี่ยน ฯลฯ) และรายการ "วิวัฒนาการมาจาก / ไปเป็น"
- รองรับร่างภูมิภาค (Alola / Galar / Hisui) เช่น Meowth → Persian (เลเวล 28) / Persian ร่าง Alola (ความสนิทสูง) / Perrserker (ร่าง Galar เลเวล 28)

### 📚 ท่าที่เรียนได้ (Moves Learned)
- แท็บ **ท่าที่เรียนได้** แยก **เรียนตามเลเวล** และ **เรียนจาก TM** เรียงจาก **ดีที่สุดไปน้อยที่สุด**
- คะแนนปรับตามสายการเล่นที่เลือก ท่าที่อยู่ในชุดดีที่สุดมี ★ (บอกปุ่ม) ชุดสำรองมี ☆

### ♥ รายการโปรด
- กดปุ่มหัวใจที่การ์ดหรือในหน้ารายละเอียดเพื่อเก็บโปเกมอนที่ชอบ
- เปิดดูรวมได้จากเมนู Start, ไอคอนบนเดสก์ท็อป หรือปุ่มหัวใจที่มุมขวาของ taskbar
- เก็บในเบราว์เซอร์ (`localStorage`) รีโหลดแล้วไม่หาย แต่**ไม่ซิงก์ข้ามเครื่อง**

### 📘 คู่มือและตาราง
- **คู่มือมือใหม่** วิธีใช้เว็บ ศัพท์ที่ควรรู้ ระบบต่อสู้เรียลไทม์ของ Z-A และหลักการจัดปุ่ม A/B/X/Y
- **คู่มือ IV/EV** หา IV, Hyper Training, ฝึก EV, Mint (ที่ซื้อและวิธีใช้)
- **ตารางธาตุ** แสดงผลการโจมตีครบทั้งตาราง
- **ตารางนิสัย** นิสัย 25 แบบ ตาราง 5×5 (แถว = ค่าที่เพิ่ม, คอลัมน์ = ค่าที่ลด) + รายการ A–Z พร้อมรสชาติที่ชอบ/ไม่ชอบ (รูปแบบอ้างอิง [pokestop.io/natures](https://pokestop.io/natures))
- **Pokédex Mega** เป็นแท็บในหน้า Pokédex แสดงเฉพาะร่าง Mega ทั้ง 97 ร่าง ค้นหา/กรองธาตุ/เรียงตามค่าพลังรวมได้ กดแล้วเปิดหน้ารายละเอียดในร่าง Mega
- **ทีมโปรด** 6 ทีม ทีมละ 6 ช่อง เลือกจากทั้งหมด/เฉพาะรายการโปรด/รวมร่าง Mega แก้ชื่อทีมได้ สรุปจุดอ่อนร่วมของทีม
- **ชาร์ตหกเหลี่ยม** ในแท็บภาพรวม (ค่าพลัง + ค่าที่เปลี่ยนตามนิสัย, ร่าง Mega เทียบกับร่างปกติ) และเครื่องคำนวณในหน้า IV/EV (ชาร์ต IV/EV และค่าพลังจริงตามเลเวล/นิสัย)

### 🪟 หน้าตาแบบ Windows
- หน้าต่างลากย้าย ปรับขนาด ย่อ ขยาย ปิดได้ มีปุ่มบน taskbar
- เมนู Start, นาฬิกา 24 ชั่วโมงพร้อมวันที่, ป้าย **Beta**, ตัวเลือกเวอร์ชันเกม (ตอนนี้มีข้อมูลเฉพาะ **Pokémon Legends: Z-A**)
- หน้าบูตแบบโหลดพร้อมโปเกมอนสุ่ม 5 ตัว
- ใช้งานบนมือถือได้ (หน้าต่างขยายเต็มจอ)

## วิธีคำนวณคำแนะนำ

> ข้อมูลส่วนนี้เป็น **การวิเคราะห์ของเว็บนี้** ไม่ใช่กฎของเกม และยังไม่ได้ทดสอบในเกมจริง

- **ท่า**: ให้คะแนนจากพลังท่า × ตัวคูณตามผลข้างเคียง (เช่น ต้องชาร์จ ลดค่าตัวเอง มีแรงสะท้อน) × STAB 1.5 × สัดส่วนค่าโจมตีที่ตัวนั้นใช้จริง แล้วเลือกท่าหลัก ท่าธาตุที่สอง ท่าครอบคลุมธาตุ และท่าเสริมตามบทบาทของสายนั้น
- **ปุ่ม**: ท่าหลัก → **A**, ท่าตีตัวที่ 2 / ครอบคลุม → **X**, ท่าเสริมพลัง → **Y**, ท่าฟื้นฟู / สถานะ / กำแพง → **B**
- **นิสัย**: ถ้าความเร็วสูง (Speed ≥ 75) จะเพิ่มความเร็ว เพราะใน Z-A ความเร็วช่วยลดคูลดาวน์ท่า ถ้าไม่ จะเพิ่มค่าโจมตีที่ใช้ตรง ๆ ส่วนสายถึกและซัพพอร์ตเพิ่มค่าป้องกันที่เด่นกว่า
- **อันดับสาย**: คำนวณจากค่าพลังพื้นฐาน (โจมตี ความเร็ว ความอึด) และจำนวนท่าสถานะที่เรียนได้ แล้วเทียบเป็นเปอร์เซ็นต์

## ติดตั้งและใช้งาน

เว็บนี้เป็นไฟล์สถิตล้วน **ไม่ต้องติดตั้งอะไร ไม่ต้อง build**

### ทดสอบในเครื่อง
```bash
python3 -m http.server 8000
# เปิด http://localhost:8000
```
เปิดไฟล์ `index.html` ตรง ๆ ในเบราว์เซอร์ก็ใช้ได้เช่นกัน

### Deploy บน GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository (จะวางที่รากของรีโป หรือใส่ในโฟลเดอร์ย่อยก็ได้)
2. ไปที่ **Settings → Pages**
3. ตั้ง Source เป็น **Deploy from a branch** เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอ 1–2 นาที แล้วเปิดลิงก์ตามโครงสร้างนี้

| วางไฟล์ไว้ที่ | ลิงก์ที่ได้ |
|---|---|
| รากของรีโป `<user>.github.io` | `https://<user>.github.io/` |
| โฟลเดอร์ `pokedex_xp/` ในรีโป `<user>.github.io` | `https://<user>.github.io/pokedex_xp/` |
| รีโปชื่ออื่น เช่น `pokedex` | `https://<user>.github.io/pokedex/` |

โค้ดใช้พาธแบบสัมพัทธ์ทั้งหมด จึงวางในโฟลเดอร์ย่อยได้โดยไม่ต้องแก้อะไร ถ้าอัปเดตแล้วยังเห็นหน้าเก่า ให้กด **Ctrl+Shift+R** หนึ่งครั้ง

### ลิงก์ตรง
เปิดหน้าที่ต้องการจาก URL ได้ เช่น `…/#/mon/153` (โปเกมอนลำดับที่ 153), `…/#/guide`, `…/#/iv`, `…/#/types`, `…/#/about`

## โครงสร้างโปรเจกต์

```
.
├── index.html          โครงหน้าเว็บ (เดสก์ท็อป, Start menu, taskbar, หน้าบูต)
├── css/style.css       ธีม XP, หน้าต่าง, การ์ด, หัวใจ, หน้าบูต
├── js/app.js           ตัวจัดการหน้าต่าง, Pokédex, หน้ารายละเอียด, รายการโปรด, เมนู
├── data/data.js        ข้อมูลทั้งหมด (window.ZA_DATA) สร้างจากสคริปต์วิเคราะห์
└── img/
    ├── mon/            artwork โปเกมอน 364 ตัว (WebP 256 px จัดกึ่งกลางแล้ว)
    ├── mega/           artwork ร่าง Mega 48 ร่าง
    ├── types/ cat/     ไอคอนธาตุและหมวดท่า
    ├── ico/            ไอคอนเดสก์ท็อปและ Start menu
    └── pokesprite-LICENSE.md
```

เลขเวอร์ชันและชื่อโปรแกรม/เวอร์ชันเกมแก้ได้ที่ `APP_VERSION`, `APP_STAGE`, `APP_NAME`, `GAME_NAME` ใน `js/app.js`

### ข้อมูลที่เบราว์เซอร์เก็บไว้ (`localStorage`)
| คีย์ | เก็บอะไร |
|---|---|
| `za_teams` | ทีมโปรด 6 ทีม ทีมละ 6 ช่อง (ชื่อทีม + โปเกมอน/ร่าง Mega) |
| `za_fav` | รายการโปรด (เลขลำดับโปเกมอน) |
| `za_welcome_seen` | ปิดกล่องต้อนรับแล้วหรือยัง |

- **รายชื่อโปเกมอนและท่าที่เรียนได้ (เลเวล / TM)**: [pokemondb.net](https://pokemondb.net/pokedex/game/legends-z-a) หน้า Legends Z-A และ [Mega Dimension](https://pokemondb.net/pokedex/game/legends-z-a/mega-dimension) · ข้อมูลเก็บมาผ่านตัวสรุปหน้าเว็บ จึงอาจมีคลาดเคลื่อนเล็กน้อย (เช่น Nacli ไม่มีหน้า Z-A จึงประมาณจากร่างวิวัฒนาการ, Munna/Igglybuff ไม่มีท่าตามเลเวลในข้อมูล)
- **สายวิวัฒนาการและเงื่อนไข / ธาตุ ค่าพลังพื้นฐาน ชื่อญี่ปุ่น และอัตราส่วนเพศของ DLC**: [PokeAPI](https://pokeapi.co/) (อ้างอิงเกมหลัก ใน Z-A บางตัวอาจต่างออกไป)
- **ชื่อญี่ปุ่น / โรมาจิ และค่าพลังพื้นฐานของ Pokédex หลัก**: เขียนจากความรู้ ไม่ได้ดึงจากเว็บ ควรตรวจกับ [Bulbapedia](https://bulbapedia.bulbagarden.net/) ถ้าต้องการความแน่นอน
- **พลังของท่า**: เป็นค่าประมาณตามเกมหลัก Z-A ใช้ระบบคูลดาวน์แทน PP จึงอาจต่างกัน
- **เพดาน EV 252 ต่อค่า / 510 รวม**: เป็นกฎของเกมหลัก Bulbapedia ไม่ได้ระบุเพดานของ Z-A จึงควรถือเป็นแนวทาง
- **ท่า / นิสัย / เพศ / ปุ่ม / อันดับสาย**: มาจากสูตรวิเคราะห์ ไม่ใช่กฎของเกม ถ้าไม่ตรงกับที่คุณเจอในเกม ให้ยึดตามเกม

โปรเจกต์นี้**สร้างโดย AI** ผ่าน **Claude (โมเดล Claude Sonnet 5.5)** ของ [Anthropic](https://www.anthropic.com/) ครอบคลุมทั้งโค้ดเว็บ การดึงและจัดข้อมูล สูตรวิเคราะห์ท่า/นิสัย/สายการเล่น และการออกแบบหน้าตา โดยมีผู้พัฒนาเป็นผู้กำหนดความต้องการและตรวจรับในแต่ละรอบ

เนื้อหาที่ AI สร้างอาจมีข้อผิดพลาด โดยเฉพาะชื่อญี่ปุ่น ค่าพลังพื้นฐาน และคำแนะนำท่า/นิสัย ควรตรวจกับเกมหรือแหล่งข้อมูลทางการก่อนใช้ตัดสินใจ
